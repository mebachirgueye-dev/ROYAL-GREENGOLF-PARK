# Theme Name: Natural
# Vibe & Description: Inspired by natural forms, the interface softens boundaries with irregular rounded corners and fluid shapes, using emotional illustrations and colors to create a human‑centered, immersive natural experience.

# Color
- Primary (Dark Slate Green): #3A5F4D, mountain & nature feel, headings, primary buttons
- Secondary (Marble Gray): #D1D5D8, whitespace, card backgrounds
- Background (Frost White): #F5F7FA, page base
- Accent (Morning Mist Blue): #8DA4B0, links, icons, active states
# Font
- Heading: GildaDisplay (url: https://resource-static.bj.bcebos.com/fonts/GildaDisplay-Regular.woff2)
- Body: 系统默认字体
# Animation
## Element Animation
- Buttons slowly lift on hover (ease-out);
- Images slowly zoom within their container on hover, rather than changing abruptly.
## Transition Animation
- When scrolling down, create a relaxed, unhurried scrolling experience. Elements fade in and float upward as they enter the viewport.

# Layout
- Instead of rigid grids, adopt a more organic, asymmetrical layout.
- Use larger margins and line spacing to allow the page to "breathe" and enhance its transparency.

# Elements
- (When necessary) I prefer to use raw image tools to generate large homepage backgrounds with abstract, soft textures;
- The use of emojis is discouraged as it can ruin the atmosphere.
- A few slowly drifting gradient shapes in the background add a sense of life.
